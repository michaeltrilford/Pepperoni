# Pepperoni agent skills

Distributable skills live in this directory. The knowledge build copies generated skills to both public and npm package outputs.

`pepperoni-components/SKILL.md` is a portable, single-file snapshot containing its workflow, relevant component APIs, composition guidance, and every authored JSON fragment. It deliberately has no `references/`, `agents/`, scripts, or asset dependencies, so downloading that one file provides the complete skill. Do not edit it directly.
